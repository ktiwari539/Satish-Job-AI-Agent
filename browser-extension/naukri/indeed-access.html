Indeed batch access

This optional permission lets a full-description batch read the Indeed job tabs it opens. Chrome grants site-level access to *.indeed.com. The agent uses it only for the up to 20 job pages in a batch you request.

Checking access…


  
  
To continue without batch access: return to your Indeed tab, open one job's full description in its own tab, then click the extension → Export current job / search. Do not click Apply.

  
This setup page reads no portal, account credentials, cookies or job data. It never changes browser policies or enables access automatically. Diagnostics contain only extension version, access status and a sanitized Chrome error. Nothing is uploaded.
